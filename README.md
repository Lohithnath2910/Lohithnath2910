## About

Final-year CS undergrad at VIT Vellore, currently sitting at a 9.37 CGPA.

I spent nine months as a research intern at IIT Delhi working on video restoration for real-world CCTV footage. That work produced RainMark, a deterministic computer vision framework for rain streak detection, which is now a published patent. Before that I shipped frontend and backend for a biotech workflow platform at Scientiflow.

I work end to end. React and Next.js on the web, Flutter on mobile, Go and Python services behind them, distributed SQL and vector stores underneath, all of it containerized and running on AWS. On the AI side that means computer vision models, RAG pipelines on locally hosted LLMs with no third-party API in the path, and generative AI wired into products rather than sitting in a notebook. I care more about latency, fault tolerance and data staying where it should than about a project looking good in a screenshot.

Comfortable across the CS stack: systems, networks, databases, ML, cloud, mobile. Blockchain and security are the two areas I have not spent real time in yet.

## Experience

**Research Intern, AI and Computer Vision** · IIT Delhi · Apr 2025 to Dec 2025

Benchmarked 20+ video restoration architectures spanning CNN, LSTM and Transformer paradigms. Built video deraining pipelines trained on 5,000+ real surveillance feeds, running multi-gigabyte training workloads on multi-GPU NVIDIA DGX clusters. Co-developed and patented RainMark, a deterministic framework for detecting and quantifying rain streaks and triaging downstream ML workloads.

**Frontend Developer Intern** · Scientiflow (Biotech) · May 2025 to Jul 2025

Built 10+ responsive Next.js modules for a scientific workflow management system, then took ownership of the FastAPI integration layer and rewired REST contracts across 5+ backend services. The rewrite cut frontend response times by roughly 30% and removed the manual data entry step researchers were doing by hand.
