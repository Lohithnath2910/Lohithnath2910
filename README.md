## About

Final-year CS undergrad at VIT Vellore, currently at a 9.37 CGPA.

I spent nine months as a research intern at IIT Delhi working on video restoration for real-world CCTV footage. That work produced **RainMark**, a deterministic computer vision framework for rain streak detection, now a published patent. Before that I shipped frontend and backend for a biotech workflow platform at Scientiflow.

I work end to end. React and Next.js on the web, Flutter on mobile, Go and Python services behind them, distributed SQL and vector stores underneath, all of it containerized and running on AWS. On the AI side that means computer vision models, RAG pipelines on locally hosted LLMs with no third-party API in the path, and generative AI wired into actual products rather than sitting in a notebook.

I care more about latency, fault tolerance and data staying where it should than about a project looking good in a screenshot.

`IIT Delhi` &nbsp;•&nbsp; `Apr 2025 to Dec 2025` &nbsp;•&nbsp; `New Delhi`

Built video deraining pipelines trained on 5,000+ real surveillance feeds, running multi-gigabyte training workloads across multi-GPU NVIDIA DGX clusters. Built 10+ responsive Next.js modules for a scientific workflow management system, then took ownership of the FastAPI integration layer and rewired REST contracts across 5+ backend services.
